# Ollama AI Chatbot

**MongoDB + Mongoose** · **shadcn/ui** · **React Hook Form** · **Docker Compose**

```bash
cp .env.example .env
docker compose up --build
```

- UI: http://localhost:5173
- API: http://localhost:3001
- MongoDB: localhost:27017

Requires Ollama locally: `ollama pull llama3.2`
